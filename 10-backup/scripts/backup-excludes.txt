# Kopia Backup Exclusion Patterns
# These paths will be excluded from backups

# === Mounted Filesystems ===
# rclone mounts (music, etc.)
**/music/**
**/mnt/rclone/**
music/**

# === Temporary & Cache Data ===
**/tmp/**
**/temp/**
**/.cache/**
**/cache/**
**/__pycache__/**
**/node_modules/**

# === Build Artifacts ===
**/dist/**
**/build/**
**/.next/**

# === Version Control ===
**/.git/**
**/.svn/**

# === Log Files (optional - uncomment to exclude) ===
# **/*.log
# **/logs/**

# === Database Transaction Logs ===
# NOTE: Do NOT exclude pg_wal — PostgreSQL requires pg_wal to recover data dirs.
# Consistent daily pg_dump backups are also stored in 05-pkm/postgres_backups/.
**/pg_log/**
**/mysql-logs/**
**/mysql-bin.*/**

# === Docker Internal ===
# Don't backup Docker's internal metadata
**/.docker/**

# === Backup Tool Data ===
# Don't backup the backup tool's own data
10-backup/kopia-cache/**
10-backup/kopia-logs/**
10-backup/kopia-repository/**

# === Large Media Files (if needed) ===
# Uncomment if you want to exclude certain media
# **/*.iso
# **/*.img
# **/*.vmdk
